# AI Automation Internship — MATalogics

This repository documents my journey through the **AI Automation Internship at MATalogics**, 
covering hands-on tasks in Git & GitHub, APIs, Airtable, n8n automation, Slack, Notion, 
voice AI agents, and end-to-end business process automation.

Each folder represents one day/module of the internship, containing the workflow files, 
configurations, screenshots, and a short write-up of what was built and learned.

## 📅 Internship Timeline

| Day / Module | Topic | Summary |
|---|---|---|
| [Day-03](./Day-03) | Git, GitHub, Postman & APIs | Learned REST APIs, HTTP methods, CRUD operations; built a Lead Management automation connecting n8n webhooks with Google Sheets, tested via Postman |
| [Day6](./Day6) | Airtable + n8n Automation Workflows | Connected Airtable to n8n and built 4 automation workflows: Lead Management, Client Onboarding, Project Tracking, and AI Agent Monitoring |
